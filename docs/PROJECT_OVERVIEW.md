# ApplyPilot — Project Overview

## Problem

Students often discover opportunities across scattered websites. Comparing eligibility, fees, deadlines, organiser details, and application requirements manually can be slow and confusing.

## Proposed solution

ApplyPilot brings the process into one place:

1. Discover opportunities from multiple sources.
2. Shortlist relevant options.
3. Compare important details side by side.
4. Use ScamShield to review source information and potential warning signs.
5. Track application progress.

## Current demo technology

- Python server (`server.py`)
- Browser-based frontend
- Tavily for web discovery
- Google Gemini and OpenAI for AI-assisted features

## Design principles

- **Clarity:** show important opportunity details in a consistent format.
- **Transparency:** distinguish confirmed information from information that is missing or uncertain.
- **User control:** assist with research and organisation; the student makes the final application decisions.
- **Practicality:** keep the workflow simple and focused.

## Important note

This document describes the current demo at a high level. It does not claim integrations that are not implemented. ElevenLabs and AWS are not currently used by the project.
